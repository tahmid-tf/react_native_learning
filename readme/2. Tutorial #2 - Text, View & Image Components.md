## 1. Core Mental Model: Mobile vs Web

In React Native, you do not use standard HTML elements (`<div>`, `<p>`, `<span>`, `<img>`). Instead, React Native components compile directly to their native platform equivalents:

| HTML Element | React Native Component | iOS Native View | Android Native View |
| :--- | :--- | :--- | :--- |
| `<div>`, `<section>` | `<View>` | `UIView` | `android.view.ViewGroup` |
| `<p>`, `<span>`, `<h1>` | `<Text>` | `UITextView` | `TextView` |
| `<img>` | `<Image>` | `UIImageView` | `ImageView` |

### Key Mobile Rules:
1. **No CSS Cascade:** Styles do not inherit down the component tree (except nested `<Text>` components).
2. **Default Flexbox Direction:** In React Native, flex containers default to `flexDirection: 'column'` (vertical), whereas web defaults to `flexDirection: 'row'` (horizontal).
3. **Strict Text Wrapping:** Any raw text string rendered outside of a `<Text>` component will crash the app with an error.

## 2. The `<View>` Component

The [`View`](file:///c:/Users/tahmi/OneDrive/Desktop/shelfie_app/app/index.jsx#L6) component is the most fundamental container for building UI layouts. It supports Flexbox layout, touch handling, style application, and accessibility controls.

### Essential Layout Properties
```jsx
import { View, StyleSheet } from 'react-native';

export default function ContainerExample() {
  return (
    <View style={styles.card}>
      {/* Children go here */}
    </View>
  );
}

const styles = StyleSheet.create({
  card: {
    // 1. Flex Layout
    flex: 1,                     // Expand to fill available screen space
    flexDirection: 'column',     // 'column' (default) or 'row'
    justifyContent: 'center',    // Main-axis alignment: 'flex-start' | 'center' | 'flex-end' | 'space-between'
    alignItems: 'center',        // Cross-axis alignment: 'flex-start' | 'center' | 'flex-end' | 'stretch'
    gap: 12,                     // Space between child elements (supported in modern React Native)

    // 2. Spacing & Dimensions
    padding: 16,
    paddingHorizontal: 20,       // Shorthand for left + right
    paddingVertical: 10,         // Shorthand for top + bottom
    marginVertical: 16,

    // 3. Visuals & Borders
    backgroundColor: '#ffffff',
    borderRadius: 12,
    borderWidth: 1,
    borderColor: '#e5e7eb',
    overflow: 'hidden',          // Clips child content that exceeds border bounds
  },
});
```

## 3. The `<Text>` Component

The [`Text`](file:///c:/Users/tahmi/OneDrive/Desktop/shelfie_app/app/index.jsx#L8) component renders text. Unlike web browsers, mobile operating systems require explicit text styling and component encapsulation.

### Critical Features of `<Text>`

#### A. Style Inheritance via Nesting
Styles do not cascade from `<View>` to `<Text>`, but nested `<Text>` components **do** inherit styles from their parent `<Text>`:

```jsx
<Text style={{ fontSize: 18, color: '#333' }}>
  This is normal text, but this word is{' '}
  <Text style={{ fontWeight: 'bold', color: '#e11d48' }}>highlighted</Text>!
</Text>
```

#### B. Text Truncation (`numberOfLines` & `ellipsizeMode`)
Essential for building card titles, previews, and list items that shouldn't overflow:

```jsx
<Text numberOfLines={2} ellipsizeMode="tail" style={styles.description}>
  This is a very long description that might span multiple lines on a mobile screen. 
  It will automatically be cut off with an ellipsis after two lines.
</Text>
```

#### C. Selectable Text
Mobile text is not selectable by default. Add `selectable={true}` for copyable text (e.g. order numbers, codes):

```jsx
<Text selectable={true} style={styles.code}>
  ORDER-98234-XYZ
</Text>
```

## 4. The `<Image>` Component

The [`Image`](file:///c:/Users/tahmi/OneDrive/Desktop/shelfie_app/app/index.jsx#L7) component displays local assets or network/remote images.

### A. Local Static Images
Import local assets using `import` or `require()`. Local images bundle with your application:

```jsx
// Option 1: Import syntax (Static asset bundling)
import logo from '../assets/icon.png';
<Image source={logo} style={styles.image} />

// Option 2: Inline require syntax
<Image source={require('../assets/icon.png')} style={styles.image} />
```

### B. Remote / Network Images (CRITICAL RULE)
When loading images from an HTTP/HTTPS URL, you **MUST** provide explicit `width` and `height` in the style, otherwise the image dimensions default to `0 x 0` and nothing will display:

```jsx
<Image
  source={{ uri: 'https://picsum.photos/400/300' }}
  style={{ width: '100%', height: 200, borderRadius: 8 }}
/>
```

### C. Understanding `resizeMode`
Controls how the image fits within its specified width and height:

```jsx
<Image
  source={logo}
  style={styles.image}
  resizeMode="contain" // 'cover' | 'contain' | 'stretch' | 'repeat' | 'center'
/>
```

- **`cover`** *(default)*: Scales proportionally to fill the container, cropping overflow if aspect ratios differ.
- **`contain`**: Scales proportionally so the entire image is visible inside the container without cropping (may leave empty space).
- **`stretch`**: Stretches non-proportionally to match the exact container dimensions.
- **`center`**: Centers the image without scaling.

## 5. Styling: StyleSheet vs Inline Styles

React Native supports both inline styles and [`StyleSheet.create`](file:///c:/Users/tahmi/OneDrive/Desktop/shelfie_app/app/index.jsx#L23).

### Why Use `StyleSheet.create` for Production?
1. **Performance**: Styles defined with `StyleSheet.create` are converted into internal IDs sent across the native bridge once, avoiding object re-creation on every render.
2. **Compile-Time Validation**: Warns you if you misspell a style property or use unsupported web CSS properties.
3. **Clean Code**: Keeps JSX markup readable and separates layout structure from visual presentation.

### Array Style Merging (Conditional Styles)
You can pass an array of styles to combine or override values conditionally:

```jsx
<Text style={[styles.baseText, isFeatured && styles.featuredText]}>
  {item.title}
</Text>
```

## 6. Lesson Code Breakdown (`app/index.jsx`)

Here is the clean breakdown of the component written in [app/index.jsx](file:///c:/Users/tahmi/OneDrive/Desktop/shelfie_app/app/index.jsx):

```jsx
import { StyleSheet, Text, View, Image } from "react-native";
import logo from "../assets/icon.png";

const Home = () => {
  return (
    // Outer container centering content vertically and horizontally
    <View style={styles.container}>
      {/* App Logo Asset */}
      <Image source={logo} style={styles.img} />

      {/* Main Heading styled via StyleSheet */}
      <Text style={styles.title}>The Number 1</Text>

      {/* Subtitle styled with inline styles */}
      <Text style={{ marginTop: 10, marginBottom: 30 }}>
        Reading List App
      </Text>
    </View>
  );
};

export default Home;

const styles = StyleSheet.create({
  container: {
    flex: 1,                   // Fill entire screen
    backgroundColor: "#fff",
    alignItems: "center",      // Center children horizontally
    justifyContent: "center",  // Center children vertically
  },
  title: {
    fontSize: 20,
    fontWeight: "bold",
  },
  img: {
    width: 200,
    height: 200,
    marginVertical: 20,        // camelCase shorthand for top and bottom margin
    borderRadius: 20,          // Rounds image corners
    marginBottom: 20,
  },
});
```

## 7. Common Pitfalls & Real-World Gotchas

| Gotcha | Why It Happens | Solution |
| :--- | :--- | :--- |
| **Blank space where network image should be** | Remote images do not have automatic dimensions. | Always define `width` and `height` on `<Image source={{ uri: '...' }} style={{ width: ..., height: ... }} />`. |
| **"Cannot render raw text outside of `<Text>`"** | Putting text directly inside `<View>hello</View>` or leaving stray spaces like `{condition && 'text'}`. | Ensure all strings and conditional text are wrapped in `<Text>`. Use boolean checks like `{isTrue ? <Text>...</Text> : null}` instead of `&&`. |
| **Property casing typo (e.g. `marginvertical`)** | React Native styles are JavaScript objects and require strict **camelCase** (`marginVertical`). | Use `marginVertical`, `marginHorizontal`, `backgroundColor`, etc. |
| **Image corners not rounding** | On Android, some nested image elements require `overflow: 'hidden'` on the wrapper or `borderRadius` directly on the `<Image>`. | Add `borderRadius` directly to the `<Image>` style or set `overflow: 'hidden'` on the parent `<View>`. |
| **Content hidden under device notch or home bar** | Standard `<View>` ignores status bars and device home indicators. | In production, wrap screen layouts in `SafeAreaView` from `react-native-safe-area-context`. |

## 8. Quick Reference Cheat Sheet

### Basic Imports
```jsx
import { View, Text, Image, StyleSheet } from 'react-native';
```

### Layout Shorthands
```javascript
paddingHorizontal: 16  // Left + Right
paddingVertical: 12    // Top + Bottom
marginHorizontal: 16   // Left + Right
marginVertical: 12     // Top + Bottom
```

### Alignment Cheatsheet
```javascript
// On default flexDirection: 'column'
justifyContent: 'center'    // Vertical centering
alignItems: 'center'        // Horizontal centering

// When flexDirection: 'row'
justifyContent: 'center'    // Horizontal centering
alignItems: 'center'        // Vertical centering
```
